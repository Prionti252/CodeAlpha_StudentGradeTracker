
# Student Grade Tracker

## Project Description
Student Grade Tracker is a beginner-friendly Java console application that calculates student grades and displays a summary report.

## Features
- Enter student name
- Enter marks for multiple subjects
- Calculate total and average marks
- Find highest and lowest marks
- Display grade based on average marks
- Validate marks between 0 and 100

## Technologies Used
- Java
- Scanner
- Arrays
- Loops
- Conditional Statements

## How to Run
1. Install Java JDK.
2. Open the project in IntelliJ IDEA.
3. Open StudentGradeTracker.java.
4. Run the main method.
5. Enter the student name, number of subjects, and marks.

## Example
For marks 85, 70, and 95:

- Total Marks: 250
- Average Marks: 83.33
- Highest Marks: 95
- Lowest Marks: 70
- Grade: A+
